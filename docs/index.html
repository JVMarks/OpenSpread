TWO TOOLS

The engine and the window.

OpenSpread

The engine, on your computer.

  • Reads public prices from Binance, OKX, Bybit, Kraken and Coinbase.
  • Shows the net spread after both taker fees. Negative stays negative.
  • Serves it locally on 127.0.0.1. Nothing leaves your machine.
  • Next: paper trading, your own Claude or Codex designing strategies, orders behind a risk policy.
OpenSpread on GitHub

Bullroom

The window: your bots as an office.

  • Seated means in a position; walking around means flat.
  • PnL floats over each head; the room sign sums the room.
  • A bot that hits its daily loss limit is ejected from the room.
  • Simulated in the browser, or live with OpenSpread.
▶ Try the demo Bullroom on GitHub
RUN IT

Two repositories. Node 22.12 or newer.

1. OpenSpread (live prices)

git clone https://github.com/JVMarks/OpenSpread.git
cd OpenSpread/core
npm install
npm start
# OpenSpread core on 127.0.0.1:4848 (read-only)

2. Bullroom (the window)

git clone https://github.com/JVMarks/bullroom.git
cd bullroom
npm install
npm run dev:client
# open http://localhost:5173/?source=core

Only Bullroom? Open ?mock=trading for simulated bots, no exchange needed. Installers for Windows and Linux are on the roadmap.

PRINCIPLES

What does not change.

Local-first

No server of ours, no cookies, no tracking. It runs on your computer.

Your keys stay home

When keys arrive, they stay on your machine, never with withdrawal permission.

The AI proposes

The engine executes, inside a risk policy you set. The AI never sends an order.

Honest numbers

Losses are shown. Simulated is always labeled. Negative stays negative.

ROADMAP

Built in stages, in the open.

  1. DONEBullroom: simulated bots, PnL over heads, room signs, bot card with 5m/1h/24h.
  2. DONEOpenSpread core: live, read-only net spreads from five exchanges.
  3. NEXTEconomic calendar and alerts in the room; machine room (API limits, latency).
  4. LATERPaper trading and backtests with Hummingbot.
  5. LATERMCP: your own Claude or Codex designing and testing strategies.
  6. LATERReal orders behind a risk policy; Nostr for identity and signed analyses.
