O QUE VOCÊ VÊ

Cada corretora é um trader. Cada par é uma sala.

Cinco corretoras, ao vivo e só leitura. A placa de cada sala mostra o melhor spread entre elas depois das taxas. Hoje ele é negativo: a diferença existe, e a taxa come tudo.

DUAS FERRAMENTAS

O motor e a janela.

OpenSpread

O motor, no seu computador.

  • Lê os preços públicos da Binance, OKX, Bybit, Kraken e Coinbase.
  • Mostra o spread líquido, já sem a taxa de compra e a de venda. Negativo continua negativo.
  • Serve tudo localmente em 127.0.0.1. Nada sai da sua máquina.
  • Próximos passos: paper trading, o seu próprio Claude ou Codex criando estratégias, ordens atrás de uma política de risco.
OpenSpread no GitHub

Bullroom

A janela: seus robôs como um escritório.

  • Sentado está posicionado; circulando está zerado.
  • O PL flutua sobre cada cabeça; a placa soma a sala.
  • O robô que bate o limite de perda do dia é ejetado da sala.
  • Simulado no navegador, ou ao vivo com o OpenSpread.

COMO RODAR

Dois repositórios. Node 22.12 ou mais novo.

1. OpenSpread (preços ao vivo)

git clone https://github.com/JVMarks/OpenSpread.git
cd OpenSpread/core
npm install
npm start
# núcleo do OpenSpread em 127.0.0.1:4848 (só leitura)

2. Bullroom (a janela)

git clone https://github.com/JVMarks/bullroom.git
cd bullroom
npm install
npm run dev:client
# abra http://localhost:5173/?source=core

Só o Bullroom? Abra com ?mock=trading para robôs simulados, sem corretora nenhuma. Instaladores para Windows e Linux estão no roteiro.

PRINCÍPIOS

O que não muda.

Local-first

Nenhum servidor nosso, nenhum cookie, nenhum rastreio. Roda no seu computador.

As chaves ficam com você

Quando as chaves chegarem, ficam na sua máquina, nunca com permissão de saque.

A IA propõe

O motor executa, dentro da política de risco que você define. A IA nunca envia ordem.

Números honestos

Perdas aparecem. Simulado é sempre marcado. Negativo continua negativo.

ROTEIRO

Construído em etapas, em público.

  1. FEITOBullroom: robôs simulados, PL sobre a cabeça, placas das salas, cartão do robô com 5m/1h/24h.
  2. FEITONúcleo do OpenSpread: spreads líquidos ao vivo, só leitura, de cinco corretoras.
  3. PRÓXIMOCalendário econômico e alertas na sala; sala de máquinas (limites das APIs, latência).
  4. DEPOISPaper trading e backtests com o Hummingbot.
  5. DEPOISMCP: o seu próprio Claude ou Codex criando e testando estratégias.
  6. DEPOISOrdens reais atrás de uma política de risco; Nostr para identidade e análises assinadas.
